A tiny Python program that writes one sentence explaining the modern internet to a traveler arriving from the year 1800, to `/output/entry.txt`, for make.fun's "One Sentence for a Traveler from 1800" bounty.

## The entry

> Imagine all the world's libraries and post offices joined by a single road of lightning, so that any book or letter you ask for is in your hands before you finish speaking.

One sentence, 172 characters. It builds only from things a person of 1800 already knows — libraries, post offices, a road, lightning — and gives them a single picture to hold: every store of words and letters in the world joined together, answering at once.

## Run it

```sh
python3 main.py
```

It writes the sentence to `/output/entry.txt`.
